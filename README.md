# 一個億的小目標

從出生到 65 歲的人生模擬遊戲。每按一次「過一年」就長一歲，目標是在 65 歲前賺到一個億。
使用 React Native + Expo（SDK 57）製作，可以用 iPhone 上的 Expo Go 直接測試。

## 在 iPhone 上測試（Windows 電腦）

1. 電腦先安裝 [Node.js](https://nodejs.org)（LTS 版）。
2. 解壓縮這個資料夾，在資料夾裡打開「命令提示字元」或 PowerShell，執行：
   ```
   npm install
   npx expo start
   ```
3. iPhone 從 App Store 安裝 **Expo Go**，用相機掃描畫面上的 QR Code，就會打開遊戲。
   - 手機和電腦要連同一個 Wi-Fi。
   - 如果掃了連不上，改用 `npx expo start --tunnel`。

## 傳說職業（12 個）

- 「找工作」清單裡選不到，只有**真的達到條件**才會有人來找你，一輩子只會遇到一次。
- 12 個：總統、太空人、天王巨星、國家隊主將、米其林主廚、神經外科權威、金牌律師、AI 科學家、財團執行長、創投大亨、金馬導演、電競世界冠軍。
- 條件多半是「屬性 + 學歷 + 做過哪一行 + 小時候學過什麼才藝」的組合，例如太空人要智力 92、健康 88、研究所以上、24～45 歲。
- 接下後：薪水約為原本的 1.5 倍、拿到專屬稱號、一筆簽約金（還有「當上傳說職業」成就 +8 點），但**高峰只有約 8 年**，任期結束就回到一般生活；沒走完的逆襲路線會暫停（回本行才會繼續）。
- 首頁有「傳說職業圖鑑」：解鎖過的會**永久保留**（換人生、重開都還在），沒解鎖的顯示 🔒 和條件。點一下看全部 12 個的條件。

## 介面

- **插圖**：場景與事件插圖採用 unDraw（MIT 授權，https://undraw.co ）的向量插畫，已全部依遊戲配色重新上色，共 31 張；人物頭像用 DiceBear avataaars（MIT 授權）依「名字」產生，同一個人每次看到都長一樣，性別、年齡（45 歲後髮色轉灰、58 歲後全白）、心情都會反映在臉上。全部是向量圖，放大不糊、離線也看得到。事件彈窗會依內容自動配圖（抓周、考試、婚禮、股災、醫院、同學會、收購、旅行、買車、面試……），主畫面依年齡與身分換場景（嬰兒 → 教室 → 校園 → 辦公室 → 公司 → 城市 → 退休），結算畫面依成績顯示城市、獎盃、房子或空錢包。

- **三個分頁**：名字列下面固定一排「🎯 本年／📊 狀態／📜 紀錄」，不用一直往下滑。
  - 本年＝主卡（年齡、淨資產、一億進度）、提示、今年要做的事、世界大事（點一下才展開）、今年摘要。
  - 狀態＝四個屬性、資產、同屆排名、職業與事業、逆襲路線，一個螢幕看得完。
  - 紀錄＝完整人生紀錄，依年齡分段，收支那類雜訊用灰色小字。
  - 在別的分頁時上面會留一條「年齡 ／ 淨資產 ／ 進度」的細長條，點一下回到本年；按「過一年」也會自動跳回本年。
- 明亮的手遊風配色。
- 第一次玩會有「開場互動教學」，一步步把畫面框起來說明（會自動切到對應分頁）；隨時可以從左上角 ☰ 選單重看。
- 開始畫面有「怎麼玩」說明頁。
- 遇到狀況（健康太低、沒工作、現金沒投資、現金快不夠）畫面會出現一行提示。

## 玩法

- **性別**：開局可以選男生或女生，交往和結婚的對象一定是異性（男生遇到的是女生、女生遇到的是男生），畫面上會用「老婆／老公」稱呼。
- **名字**：遊戲裡遇到的人（對象、同學、小孩）都是完整的姓名，例如「陳怡君」「林志明」；小孩會自動跟著你的姓（角色叫「王大明」，小孩就是「王承翰」）。

- **難度**：開局可以選輕鬆／普通／挑戰／☠️ 地獄，影響投資報酬、事業成長、生活費和起薪。
  - 地獄難度另外還有：出身多半清寒、天賦較差（起始屬性 -6）、薪水只有 65%、生活費兩倍、股災和疫情出現機率 1.8 倍、通膨更兇、每年健康風險 +2。認真玩大約 24% 能破一億。

- **3 歲上幼兒園**：公立（抽籤、省錢）／私立（有才藝課，清寒家庭選不了）／雙語（外師全美語，只有富裕和豪門選得到，會拿到英文加成）／阿嬤帶（免費，超快樂但智力少一點）。
- **5 歲資優鑑定**：智力 62 以上會遇到，可以選擇**跳級**——會考、學測、畢業全部提前一年，等於多一年可以賺錢，但人緣和快樂會掉一點。
- **13 歲選社團**：熱門音樂社、籃球隊、科學研究社、熱舞社、演辯社、電競社，或是不參加專心讀書，各有不同的屬性加成。
  - 選熱音社之後會遇到「要不要組團？」→「校際熱音大賽」→ 得名的話影片會爆紅 →「Live House 找你們暖場」（有演出費）。
- **當偶像**：人緣 55 以上、國高中時期會被星探攔下來 → 試鏡 → 練習生 → 出道評測 → 出道後跑通告賺錢、接偶像劇，也可能被週刊拍到要開記者會。當過偶像對之後解鎖「天王巨星」很有幫助。
- **0–6 歲**：童年有 30 多個專屬事件（學走路、第一天上幼兒園、學腳踏車、過年紅包……）。1 歲的「抓周」有 18 樣東西，每次隨機擺出 5 樣。
- **6–12 歲**：小學生活有 22 個專屬事件（選班長、運動會大隊接力、科展、撿到錢包、班上有人被欺負、才藝課不想學了、過年紅包、颱風假、隔宿露營、在班上做小生意……），很多都要做選擇。
- **6–17 歲**：每年可以同時選好幾件事（讀書、補習、運動、玩樂、交朋友、打工、學理財）。15 歲考會考，18 歲考大學（跳級的話全部提前一年）。
- **出社會後**：每年可以同時選好幾件事（預設 3 件，可以在首頁用傳承點數永久升到 5 件）（認真工作、進修、休息、健身、人脈、研究投資、找工作、創業、經營事業）。
- **投資**：滿 18 歲才能開戶（v77 起；之前是從出生就能投資），有大盤與個股比較圖，以及每年「大盤 vs 我的投資」明細表。有定存、ETF、個股、黃金、加密貨幣、定期定額、房地產、事業、貸款。
- **逆襲路線**：每個職業都有一條專屬劇情，會一步步把角色帶向一個億。多選「認真工作」，劇情比較常出現。
- **世界大事**：每年抽一個（AI 熱潮、疫情、戰爭、金融海嘯、升息、降息、油價飆漲、房市狂熱……），會影響股市、房價、各行業和通膨。
- **通膨**：物價每年上漲，生活費、養小孩、房價都會變貴，薪水也會跟著調整一部分。
- **健康偵測**：隱藏的健康風險會因為過勞、壓力、年紀累積。做健康檢查可以看到風險，及早治療。
- **家庭**：結婚後選「家庭時光」可以生小孩（最多 6 個），可以看到每個孩子花了多少錢。
- **生育年齡**：生小孩的機率和結果會看「媽媽」的年齡（你是女生就是你自己，男生就看另一半，結婚時決定，跟你差 4 歲以內）。
  - 沒懷上的話會休息兩年再試；35 歲以後的失敗還要付檢查和療程的費用（35–37 歲 5 萬、38–39 歲 10 萬、40 歲以上 20 萬，隨物價調整）。
  - 受孕成功率：30 歲前 95%、30–34 歲 88%、35–37 歲 72%、38–39 歲 58%、40–42 歲 38%、43–44 歲 22%、45 歲以上 10%。沒懷上會顯示「試了一整年，還是沒有消息」。
  - 唐氏症（21 三體）機率採用接近真實的數字：35 歲約 0.4%、40 歲約 1%、43 歲約 2.8%、45 歲以上約 4%。
  - 唐寶寶 22 歲前每年多一筆早療和療育的費用（8 萬，不隨養育方式加成）；成年後會有自己的工作（庇護工場、支持性就業……），家裡每年再給 5 萬生活費，沒有孝親費。
  - 「家庭」頁會顯示媽媽目前的年齡、受孕成功率和唐氏症機率。
- **窮養／標準／富養**：每個小孩都可以個別選養育方式，隨時能改。
  - 窮養 ×0.55、標準 ×1.0、富養 ×2.2（富養含私立學校、才藝、補習、遊學）。
  - 22 歲獨立時會依養育方式擲出成就：窮養約 39% 工作不穩、54% 普通上班族；標準約 47% 普通、44% 專業人士；富養約 51% 很有成就、43% 專業人士（父母智力／人緣／快樂高也會加分）。
  - 孩子 25 歲起每年給孝親費：普通上班族 3 萬／專業人士 8 萬／很有成就 18 萬（隨物價調整），會出現在〈今年摘要〉。
- **公司**：最多同時經營兩家自己開的公司。
- **收購**：淨資產突破一億後解鎖，投資頁多一個「收購」分頁，每年換一批待售公司，共 9 種情境：
  - **急售**（折價 15～35%）、**家族接班**（折價，但要人緣 60 以上）、**法拍／重整**（很便宜，但接手後才知道實際價值，可能只剩四成也可能賺一倍）
  - **競標**（有別的買家，可以選照開價出／加價一成／加價三成，加得越多越容易標到，人緣也會加分）
  - **同業對手**（很貴，但同產業一起受惠）、**海外公司**（成長高、波動大）、**新創團隊**（金額小，可能翻倍也可能歸零）、**上市公司股權**（大而穩、波動低）、**一般出售**
  - 付款可以選現金或貸款六成；集團裡每多一家同產業就有綜效（年成長 +0.6%，最多 +1.8%）；買下來不占自己開的兩家名額，集團最多 8 家
  - 收購後還會遇到整頓公司（投資／留用原團隊／裁員）、同產業整併、子公司出包、有人想高價買走你的公司等事件
- **同屆同學**：開局就決定好 5 個同學，各走各的路（公務員、工程師、醫生、創業家、網紅、專職投資、繼承家業、打零工……），資產每年變化，股災時創業和投資的人跌最重。主畫面有「同屆排名」卡片，點開看排行榜；25 歲之後每 5 年一次同學會，可以請客、交換情報或立志超越第一名；退休結算會比最後名次。
- **行業**：47 種職業，每一種都有專屬的逆襲路線和公司類型。
- **同一份工作有好幾條路進去**：20 種職業有「另一條路」，用你最強的屬性也能進同一個行業，職稱會不一樣——智力高可以當「知識型網紅」「顧問式業務」「不動產分析師」「臨床心理師」，人緣高可以當「人氣名師」「理財業務」「財富管理業務」，體力好可以當「運動型網紅」「運動分析師」。網紅類的收入會看你是靠哪個屬性進去的（智力型就看智力）。
- **職缺是隨機的**：每次「找工作」會從你符合資格的職業裡隨機端出 2～5 個，**不會固定把最高薪的塞進來**。所以就算你是頂尖研究所畢業，也可能這一年只有超商和外送在徵人——不滿意就明年再選「找新工作」碰運氣。
- **另一半靠自己升遷**：結婚後另一半會在自己的行業裡慢慢往上爬（同一個職位至少 3 年，每年有機會升一級；家裡快樂、你多選「家庭時光」升得比較快，負債時比較慢），職稱照他原本的行業一路往上，不會全部變成「成功企業家」。例如護理師 → 專科護理師 → 護理長 → 護理督導 → 護理部主任 → 醫院副院長；藥師 → 資深藥師 → 藥局組長 → 藥劑部主任 → 連鎖藥局經理 → 藥妝集團總監。21 種對象各有自己的六階路線。
- **學歷不夠也能被挖角**：同一份工作做滿 5 年，可以應徵比自己學歷高一級的工作（職缺會標 ★）。所以只顧著交朋友或運動的人，出社會後靠年資一樣爬得上去。
- **才藝**：30 種才藝（鋼琴、程式、珠心算、英文會話、理財課……），小時候每次會隨機端出 4 種讓你挑，學過的不會再出現。**長大後還會繼續有用**：音樂和攝影可以接案賺副業、英文和程式讓薪水變高、運動類讓你老得慢、演講讓升遷更容易、烹飪省生活費、理財課讓投資多賺（各項都有上限）。
- **事件**：229 個隨機事件，每年會有 1～2 件小事，加上一件需要做選擇的大事。
- **寵物**：可以養狗或養貓，飼料、疫苗、看醫生、美容……每一筆花費都會記在「家庭」頁。
- **戀愛**：學生時期就可以交往。「有人想介紹對象給你」會隨機端出 3 個人選讓你挑，每一種對象都有自己的專長：護理師讓你老得慢、包租婆買房便宜、會計師省生活費、幼教老師養小孩便宜、銀行理專讓投資多賺、富二代結婚直接包 800 萬……結婚後對方每年還會為家裡賺錢。約會、情人節、旅行都要花錢，感情太淡會分手（選「約會」感情 +24，沒約會每年只掉 1～3）。**交往滿 1 年、感情 40 以上，就可以在「家庭」頁直接求婚**（辦婚禮或登記就好），不用等事件。
- **站上頂峰**：破億之後，只要是同屆第一名或淨資產 3 億以上，主卡會出現「👑 你是最強的那一個」，然後錢會自己找上門——品牌搶著找你代言、老同學要把錢交給你管、投資人排隊想投你的公司、母校頒榮譽博士、出版社搶著出自傳、上市公司請你當董事、有人在門口塞紅包想拜師、富豪俱樂部邀你合資，還有失聯十年的親戚全部出現。金額跟著你的身家變大。
- **現金不夠時**：遊戲**不會自己賣掉你的資產**。入不敷出會先算成負債（每年滾利息），借到銀行上限時才會跳出來問你要賣哪一樣（各種投資、房子，或什麼都不賣、縮衣節食）。
- **傳承點數與永久升級**（跨存檔保留）：
  - 每玩完一輩子，會依照那一生的**成就**換成點數：平安活到退休 +3、達成一億 +10、提早破億 +3～6、資產每翻一倍 +3、完成逆襲路線 +6、當上傳說職業 +8、同屆第一名 +4、跳級 +2、明星高中 +1、頂尖大學／研究所 +2～3、偶像出道 +3、熱音大賽得名 +2、結婚 +2、每個孩子 +1、孩子很有成就 +2、買房 +1、開公司 +2、收購公司 +3。
  - 難度加成：輕鬆 ×0.7、普通 ×1、挑戰 ×1.3、地獄 ×1.8。
  - 首頁「永久升級」可以買：**每年多做一件事**（3 → 4 件 40 點、4 → 5 件 80 點）、**延後退休**（每延 1 年 8 點起，每次貴 2 點，最多到 80 歲）。買了之後以後每一輩子都有效。
  - 遊戲中右上角「🏅 成就」可以看這一輩子目前拿到哪些成就、結算時能換幾點；退休結算畫面會列出完整清單。
  - 平衡：新手（沒有升級）普通難度認真玩 98%、地獄 23%；全部升滿後地獄認真玩約 51%。
- **零用錢**：家境越好，小時候的零用錢和出社會時的起步金越多；滿 18 歲才能投資，之前的錢先存成現金。
- **退休結算**：顯示淨資產、稱號、資產變化圖、最賺錢的決定和最大的失誤。

## v34：接送、轉職鎖、偶像合約
- 6 歲上小學會問「誰接送」（爸媽／阿嬤／安親班／自己走）。幼兒園選「阿嬤帶」的人，6 歲這題沒有「爸媽接送」可選。12 歲升國中再問一次要不要改（阿嬤→爸媽／自己搭公車）。接送方式每年有一點屬性影響（`flags.pickup`）。

- 投資頁「貸款」分頁可以主動借「信用貸款」（`E.borrow` / `E.loanInfo`）：20 歲以上、額度＝三年收入＋存款一半＋投資與房產淨值三成，利率 6%、7 年本利攤還，`debts[].personal = true`。

- 偶像合約到期多了「自己開經紀公司」（要 300 萬×物價的現金，開「演藝經紀公司」）。
- 有貸款又還不出錢（現金透支到銀行上限）：銀行**強制處分**資產（定存→黃金→個股→加密幣→ETF，不夠再法拍房子），不會再問你。沒有貸款、只是現金透支的人才會跳「要賣什麼」的選擇。狀態卡的「負債」現在會把現金透支也算進去，現金為負時顯示「現金（透支）0」。
- 創業可選的行業從 3 種擴到 23 種（`BUSINESSES` 標 `open: true`）：補習班／飲料店／科技新創一定在，另外每次隨機抽 4 種（已經開過的不重複），第二次創業也一樣。
- 同學會「跟第一名的同學拚一下」現在會在下一次同學會結算：超過他 → 快樂+8、人緣+4、+2 點；沒超過 → 快樂-6、健康-3，連續輸第二次 ×2、第三次起 ×4（`flags.rivalLoss`），贏一次就歸零。
