一個億的小目標．網站版

【放到網路上：GitHub Pages（免費、不用 Netlify）】
第一次設定（大約 5 分鐘）：
  1. 用電腦登入 https://github.com （你的帳號 stevenwang21）。
  2. 右上角「＋」→「New repository」。
     - Repository name 填：yiyi-game
     - 選「Public」（免費版的 GitHub Pages 需要公開）
     - 按「Create repository」。
  3. 在新的 repository 頁面，點「uploading an existing file」。
  4. 打開這個資料夾，全選裡面所有檔案和 art 資料夾（Ctrl + A），
     直接拖進網頁，等上傳完成後按下方綠色的「Commit changes」。
     （注意：是拖「資料夾裡面的東西」，不是拖整個資料夾本身）
  5. 上方點「Settings」→ 左邊「Pages」→
     Source 選「Deploy from a branch」，Branch 選「main」、資料夾選「/ (root)」→「Save」。
  6. 等 1～2 分鐘，重新整理 Pages 那一頁，上方會出現網址：
     https://stevenwang21.github.io/yiyi-game/

之後更新遊戲：
  到 repository 首頁 →「Add file」→「Upload files」→ 把新的 app.js、sw.js（有新圖片就加上 art 資料夾）拖進去 →「Commit changes」。
  1～2 分鐘後網站就會更新。手機上關掉再打開遊戲兩次，就會換成新版。

【安全】
  - 這是純前端網站：沒有伺服器、沒有資料庫、不收帳號密碼，存檔只放在每個玩家自己的手機裡，別人拿不到。
  - index.html 已加上安全設定（Content-Security-Policy），只允許執行網站自己的程式，就算有人想塞惡意腳本也跑不起來。
  - 最重要的是保護 GitHub 帳號：到 GitHub → Settings → Password and authentication → 開啟「Two-factor authentication（兩步驟驗證）」。

【下載到 iPhone】
  1. 用 Safari 打開上面的網址。
  2. 按下方的「分享」按鈕 →「加入主畫面」→「新增」。
  3. 主畫面會出現「一個億」圖示，點開就是全螢幕的遊戲。
  4. 第一次打開後，沒有網路也能玩；進度會自動存在手機裡。
  （網址換了，舊網址裡的存檔不會自動搬過去，要重新開始玩）

【Android】
  用 Chrome 打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」。

【其他放法】
  Netlify Drop：https://app.netlify.com/drop 把整個資料夾拖進去（免費額度用完時會不能上傳）。
