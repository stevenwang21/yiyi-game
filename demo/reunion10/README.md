# 同學會十秒場（獨立雛型）

這是一個**獨立的展示**，還沒接進遊戲本體。遊戲是 Expo / React Native，
這裡用的是網頁版的 React + Framer Motion + Tailwind，兩邊的動畫寫法不一樣。
放在這裡只是先留著看效果、討論要哪幾個動作。

## 兩個檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 打開就能玩。React / Framer Motion / Tailwind / Babel 都從 CDN 載，人物圖讀本資料夾的 `art/` |
| `Reunion10sScene.jsx` | 單一檔案 React Component，貼進 CodeSandbox 就能跑。頭像用 placehold.co 佔位圖 |

`index.html` 要看的話不能直接點兩下開（瀏覽器會擋本機檔案讀圖），在這個資料夾開終端機跑：

```
python -m http.server 8080
```

然後開 http://localhost:8080

## 四個選項的十秒動畫

沒選之前是「待機用餐」：六個人各自輕輕呼吸晃動（節奏錯開），轉盤上的菜慢慢轉。

| 選項 | 0–2 秒 | 2–5 秒 | 5–8 秒 | 8–10 秒 |
|---|---|---|---|---|
| 大方請客 | 主角升起放大 | 金色 VIP 卡拿出來、「今天我請客！」彈出 | 全場舉杯 🥂🙌🍻🎉＋彈跳＋彩帶 | 結果卡 |
| 低調吃飯聊天 | 燈光壓暗 | 每人面前出現碗、冒熱氣 | 對話泡泡＋全場 😆🍻🥢 | 結果卡 |
| 交換投資情報 | 大家往前傾 | 走勢圖升起、線條自己畫出來 | 全場 👏🤔📈😮🤫 反應 | 結果卡 |
| 跟第一名拚一下 | — | 座位不動，舞台下方浮出資產折線圖（你金色／對手紅色） | 線畫完，不加敬酒特效 | 結果卡 |

拚一下那個是照遊戲裡原本的做法（`src/ui/Character.js` 的 `RivalChart`），沒有改。

## 人物圖規格

`art/f_*.webp` 是從 `public/art/cm_*.webp` 和 `char_young_m.webp` 來的：
去掉四周空白（切齊頭頂和鞋底）再統一縮成 460px 高。

版面是**用身高排的**，六個人平均分散成一排（中心點 9 / 25 / 41 / 57 / 73 / 89 %），
每個人在畫面上一樣高（玩家高一點），鞋子落在前景圓桌的上緣，所以要換圖的話
一定要先切齊頭頂和鞋底，不然身高會對不齊。

## 要接進遊戲的話

動畫要改寫成 React Native 的 `Animated`（就是 `src/ui/Character.js` 裡
`ReunionStage` 那一套）。這個資料夾的內容不會被 `expo export` 打包，
放著不影響遊戲的建置和部署。
